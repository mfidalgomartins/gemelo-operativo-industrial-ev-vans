# Changelog

All notable changes to this project are documented here. The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project
adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Changed

- Stopped tracking the 34 MB `data/processed/gemelo_operativo_ev.duckdb` binary
  in git. It is a rebuildable intermediate; the committed CSV marts remain the
  canonical outputs and the database is regenerated by the pipeline.

### Added

- Community-health files: `CONTRIBUTING.md`, `SECURITY.md`,
  `CODE_OF_CONDUCT.md`, `CITATION.cff`, issue templates, and a pull-request
  template.
- Enforced coverage gate in CI: the `integration` job now runs the full suite
  with `--cov-fail-under=85` (measured combined coverage is ~90%).
- Status badges (CI, license, Python, coverage) in the README.
- `GOAL.md` documenting the repository-quality target and the actions taken.

## [1.0.0] — 2026-04-05

### Added

- Initial public release of the EV-transition operational digital twin.
- Deterministic synthetic-data generator (orders, assets, constraints,
  operational events) under `src/synthetic_data_gen/`.
- DuckDB SQL layer building staging, integrated views, marts, KPIs, and
  business checks.
- Analytical layer: feature engineering, diagnostics, parametric scenario twin,
  Operational Priority Index with weight-sensitivity and Monte Carlo stability.
- Release gate enforcing data contracts, KPI consistency, and dashboard
  contracts (decision-support only).
- Published deliverables: 19-chart pack, standalone interactive dashboard, and a
  34-page analytical PDF report.
- CI with lint, format, multi-version unit tests, packaging, integration, and
  security (bandit + pip-audit) jobs.
